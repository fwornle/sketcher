# Troubleshooting

The common failures and how to fix them.

=== "⚡ Quick (~2 min)"

    ## Most common fixes

    | You see | Do |
    |---|---|
    | Amber *No API key set* hint | Add a key under **Settings → API Keys** |
    | *Authentication failed…* | The key is wrong or revoked: create a new one |
    | *…rate limit exceeded* / *…quota exceeded* | Wait a minute, or check billing with the provider |
    | *Failed to fetch* | The browser cannot reach the API: check network, VPN, ad blocker |
    | Preview stuck on *Loading diagram…* | `embed.diagrams.net` is blocked: use **Download .drawio** |
    | Shapes missing or misplaced | Retake the photo straight-on, cropped, with dark markers |
